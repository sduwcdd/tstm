# TSTM: Temporal Segmentation for Task-relevant Mask

This is the official PyTorch implementation of **TSTM** from

**TSTM: Temporal Segmentation for Task-relevant Mask in Visual Reinforcement Learning Generalization** by

Weicheng Du, Wenjia Meng, Zhengzhe Zhang, Yilong Yin, Xiankai Lu.

**CVPR 2026**

[[Paper]](https://openaccess.thecvf.com/content/CVPR2026/html/Du_TSTM_Temporal_Segmentation_for_Task-relevant_Mask_in_Visual_Reinforcement_Learning_CVPR_2026_paper.html) [[Supplementary Material]](https://openaccess.thecvf.com/content/CVPR2026/supplemental/Du_TSTM_Temporal_Segmentation_CVPR_2026_supplemental.pdf)

The implementations for DeepMind Control Suite and robotic manipulation are available in [TSTM_on_DMC](TSTM_on_DMC/) and [TSTM_on_Robotic_Manipulation](TSTM_on_Robotic_Manipulation/), respectively. Please refer to their READMEs for installation and training instructions.
